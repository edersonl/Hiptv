# HIPTV

Aplicativo Android desenvolvido em .NET 9 para reprodução de playlists IPTV (M3U), com suporte a favoritos, histórico de reprodução e funcionalidade Continue Watching.

## Funcionalidades

- Reprodução de playlists M3U
- Lista de canais
- Favoritos
- Histórico de canais recentes
- Continue Watching (continuação da reprodução)
- Busca de conteúdo
- Reprodução via Media3
- Fallback automático para MediaPlayer legado
- Interface otimizada para Android

## Tecnologias

- .NET 9
- Android SDK
- AndroidX Media3
- C#
- XML Layouts
- Android Activities
